## 2584 Fibonacci
2584 Fibonacci aka 2048 game

Фибоначчи-вариант 2048
Eправление как в 2048 - движение цифр на игровом поле на четыре стороны, свайпом мыши для ПК.
Соединяются между собой соседние цифры ряда фибоначчи. 
Цифры фибоначи образуется путем сложения двух предыдущих чисел.
Первые цифры ряда - 1, 2, 3, 5, 8, 13, 21, 33, 54...... и так далее, по учебнику. 
Ряд начинается с единицы, которая соединяется 
с 1 и 2
2 с 1 и 3
13 с 8 и 21 
Возможно несколько соединений в ряду сразу - цепная реакция - как в 2048. 
Игра заканчивается, когда исчезает свободное место на игровом поле.

Шрифты в проекты бесплатные, созданные для российского сегмента сети вроде как для всех, сайт paratype.ru
